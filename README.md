# Onewheel GT Teardown

An interactive, exploded 3D view of a Onewheel GT. Click any part to see what
it does, how it connects to the rest of the board, and common upgrade or
replacement options.

**Live page:** https://jreed6.github.io/onewheel-gt-teardown/

- Single static page (`index.html`) built with [three.js](https://threejs.org/)
  r128, loaded from a CDN. No build step.
- To run locally, open `index.html` in a browser.

This is a simplified teaching model with approximate proportions. It is not a
repair guide and is not affiliated with Future Motion.
